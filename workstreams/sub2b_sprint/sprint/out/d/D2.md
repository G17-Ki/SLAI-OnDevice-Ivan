## Verdict

## Exact Silero count

Pinned repo revision: `d9355348e2781dc8fa25a135d1602c530afae24c`. The exact downloaded model bits are pinned by SHA-256 `ba41b18f6a707ad93605a162998865e7c087153d2e010a26dd02229dab0e672a` (91,680,514 bytes). The URL itself is not revision-addressed.

The `.pt` is a `torch.package` archive, not a bare root ScriptModule. I loaded `tts_models/model` with `torch.package.PackageImporter`, traversed `wrapper.packages[*].models[*]`, found one `torch.jit.RecursiveScriptModule`, and evaluated:

```python
sum(p.numel() for package in wrapper.packages
              for module in package.models
              for p in module.parameters())
```

This summed 306 parameter tensors to **20,926,952**. The independent reconciliation tied exactly: 22,850,584 `state_dict` elements minus 1,923,632 registered-buffer elements equals 20,926,952. The 11 excluded buffers are positional encodings, PQMF filters, and an ISTFT window. The full tensor inventory is in `artifacts/d2/meta/silero_parameter_inventory.json`.

One important operational correction: `v5_cis_base` does **not** bundle an accentor in the loaded artifact (`accentor == None`). Its documentation says stress must be supplied explicitly. The Silero clip therefore uses manually marked stress. A production route needs an explicit stress front end; unmarked-text pronunciation is not established here.
